Sprite Calendar — README

Что это

Календарь на Java (Swing) с событиями, опросами и P2P-синхронизацией между пользователями.

---

Запуск

1. Установи Java 17+ (нужен java в PATH).
2. Запусти start.bat — он скомпилирует и запустит программу.

---

Основные возможности

· Просмотр календаря по месяцам (стрелки внизу).
· Клик по дню открывает меню дня: добавить событие (текст, тип, цвет), создать анонимный опрос (вопрос и варианты, голосование), удалить день.
· Всё сохраняется в файл calendar_save.dat в папке с программой.

---

Сеть (P2P)

Кнопка «Сеть» в левом верхнем углу открывает меню.

Стать хостом: укажи порт (по умолчанию 9876) и нажми «Стать хостом». Сообщи свой IP и порт друзьям — IP показан в окне.

Подключиться к хосту: введи IP хоста и порт, нажми «Подключиться».

Синхронизация календаря: кнопка «Синхронизировать календарь» рассылает твоё состояние всем подключённым. Новый подключившийся автоматически получает состояние хоста.

Обмен файлами: папка shared рядом с программой — это общая папка. «Загрузить…» добавляет файл в shared и рассылает пирам, «Скачать» скачивает выбранный файл у первого подключённого пира, «Обновить» перечитывает локальную папку и рассылает список. Большие файлы передаются медленно.

---

Файлы и папки

Сохранение календаря лежит в calendar_save.dat в папке с программой. Общая папка для обмена файлами — shared. Запуск — через start.bat.

---

Известные ограничения

· Синхронизация простая: состояние целиком перезаписывается, без разрешения конфликтов.
· Порт должен быть доступен. При игре через интернет нужен проброс порта или VPN типа Radmin/Hamachi.
· Файлы принимаются только с именем без /, \, ...

---

Быстрый старт на двоих

Оба запускают start.bat. Первый: «Сеть» → «Стать хостом» → запоминает IP. Второй: «Сеть» → вводит IP хоста → «Подключиться». Дальше события и опросы синхронизируются кнопкой «Синхронизировать календарь», файлы — через папку shared.
